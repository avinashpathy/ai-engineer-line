## Setup

<Level l="advanced" />

All three models train on MNIST (28×28 grayscale digits) in minutes on a free Colab or Kaggle GPU. They share this setup:

```python title="setup.py"
import torch, torch.nn as nn, torch.nn.functional as F
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

device = "cuda" if torch.cuda.is_available() else "cpu"
tfm = transforms.Compose([transforms.ToTensor()])          # pixels in [0, 1]
dl = DataLoader(datasets.MNIST("data", train=True, download=True, transform=tfm),
                batch_size=128, shuffle=True)
```

## Variational autoencoder

<Level l="advanced" />

```python title="vae.py"
class VAE(nn.Module):
    def __init__(self, z_dim=16):
        super().__init__()
        self.enc = nn.Sequential(nn.Flatten(), nn.Linear(784, 400), nn.ReLU())
        self.mu, self.logvar = nn.Linear(400, z_dim), nn.Linear(400, z_dim)
        self.dec = nn.Sequential(nn.Linear(z_dim, 400), nn.ReLU(), nn.Linear(400, 784), nn.Sigmoid())

    def forward(self, x):
        h = self.enc(x)
        mu, logvar = self.mu(h), self.logvar(h)
        z = mu + torch.exp(0.5 * logvar) * torch.randn_like(mu)     # reparameterisation trick
        return self.dec(z).view(-1, 1, 28, 28), mu, logvar

def vae_loss(x_hat, x, mu, logvar):
    recon = F.binary_cross_entropy(x_hat, x, reduction="sum")
    kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())   # KL(N(mu, sigma^2) || N(0, 1)), closed form
    return (recon + kl) / x.size(0)

vae = VAE().to(device)
opt = torch.optim.Adam(vae.parameters(), lr=1e-3)
for epoch in range(10):
    for x, _ in dl:
        x = x.to(device)
        x_hat, mu, logvar = vae(x)
        loss = vae_loss(x_hat, x, mu, logvar)
        opt.zero_grad(); loss.backward(); opt.step()
    print(epoch, round(loss.item(), 1))

with torch.no_grad():                                               # generate brand-new digits
    samples = vae.dec(torch.randn(16, 16, device=device)).view(-1, 1, 28, 28)
```

<Example title="Worked example: the KL term">
For one latent dimension with μ = 0.5 and log σ² = 0 (so σ = 1):
KL = −½ (1 + 0 − 0.25 − 1) = **0.125**.

With μ = 0 and σ = 1 the KL is **0**. The encoder is penalised for drifting away from the standard normal, which keeps the latent space smooth and easy to sample from.
</Example>

VAE samples are usually **blurry**: the reconstruction loss averages over all plausible outputs. That motivated GANs and diffusion, but VAEs live on as the compression stage inside latent diffusion. Stable Diffusion's VAE turns a 512×512×3 image into a 64×64×4 latent.

## GAN (DCGAN-style)

<Level l="advanced" />

```python title="gan.py"
z_dim = 64
G = nn.Sequential(                                           # noise -> 28x28 image
    nn.Linear(z_dim, 128 * 7 * 7), nn.BatchNorm1d(128 * 7 * 7), nn.ReLU(), nn.Unflatten(1, (128, 7, 7)),
    nn.ConvTranspose2d(128, 64, 4, 2, 1), nn.BatchNorm2d(64), nn.ReLU(),          # 14x14
    nn.ConvTranspose2d(64, 1, 4, 2, 1), nn.Tanh()).to(device)                      # 28x28 in [-1, 1]

D = nn.Sequential(                                           # image -> real/fake logit
    nn.Conv2d(1, 64, 4, 2, 1), nn.LeakyReLU(0.2),
    nn.Conv2d(64, 128, 4, 2, 1), nn.BatchNorm2d(128), nn.LeakyReLU(0.2),
    nn.Flatten(), nn.Linear(128 * 7 * 7, 1)).to(device)

optG = torch.optim.Adam(G.parameters(), lr=2e-4, betas=(0.5, 0.999))
optD = torch.optim.Adam(D.parameters(), lr=2e-4, betas=(0.5, 0.999))
bce = nn.BCEWithLogitsLoss()

for epoch in range(20):
    for x, _ in dl:
        real = x.to(device) * 2 - 1; b = real.size(0)
        fake = G(torch.randn(b, z_dim, device=device))
        # 1) Discriminator: real -> 1, fake -> 0
        lossD = bce(D(real), torch.ones(b, 1, device=device)) + \
                bce(D(fake.detach()), torch.zeros(b, 1, device=device))
        optD.zero_grad(); lossD.backward(); optD.step()
        # 2) Generator: make D say "real" for fakes (the non-saturating loss)
        lossG = bce(D(fake), torch.ones(b, 1, device=device))
        optG.zero_grad(); lossG.backward(); optG.step()
    print(epoch, round(lossD.item(), 3), round(lossG.item(), 3))
```

The game being played is:

```
min_G max_D  E[log D(x)] + E[log(1 − D(G(z)))]
```

**Training tips:** Adam with β₁ = 0.5; LeakyReLU in the discriminator; label smoothing (use 0.9 instead of 1 for "real"); don't let the discriminator get too strong; watch for mode collapse (all samples look alike).

**Variants worth knowing:** WGAN-GP (Wasserstein loss with gradient penalty, much more stable), StyleGAN (photo-real faces), conditional GANs (generate a requested class), CycleGAN (unpaired image-to-image translation, e.g. summer ↔ winter).

## Diffusion: the maths

<Level l="advanced" />

### Forward process

Choose a noise schedule β₁ … β_T (for example rising linearly from 0.0001 to 0.02 over T = 1,000 steps). Let αₜ = 1 − βₜ and ᾱₜ be the running product of the αs. Then a noisy version at *any* step can be sampled in one shot:

```
xₜ = √ᾱₜ · x₀ + √(1 − ᾱₜ) · ε,     ε ~ N(0, I)
```

<Example title="Worked example: how much signal remains">
If ᾱₜ = 0.25 at some step, then xₜ = 0.5·x₀ + 0.866·ε: noise already dominates. By the last step ᾱ_T ≈ 0.00004 — essentially pure noise.
</Example>

### Training objective (DDPM)

Pick a random step t, noise the image to that step, and train a network ε_θ to predict the noise that was added:

```
L = ‖ ε − ε_θ( √ᾱₜ·x₀ + √(1 − ᾱₜ)·ε , t ) ‖²
```

A plain mean-squared error. That simplicity is a big part of why diffusion trains so reliably.

### Sampling (reverse process)

Start from pure noise x_T and step backwards:

```
xₜ₋₁ = (1/√αₜ) · ( xₜ − (βₜ / √(1 − ᾱₜ)) · ε_θ(xₜ, t) ) + σₜ·z
```

## A minimal diffusion model in code

<Level l="advanced" />

```python title="diffusion.py"
T = 400
betas = torch.linspace(1e-4, 0.02, T, device=device)
alphas = 1 - betas
abar = torch.cumprod(alphas, 0)

class TinyUNet(nn.Module):                        # small conv net, conditioned on the timestep
    def __init__(self, ch=64):
        super().__init__()
        self.t_emb = nn.Sequential(nn.Linear(1, ch), nn.SiLU(), nn.Linear(ch, ch))
        self.down1 = nn.Sequential(nn.Conv2d(1, ch, 3, padding=1), nn.SiLU())
        self.down2 = nn.Sequential(nn.Conv2d(ch, ch * 2, 4, 2, 1), nn.SiLU())          # 14x14
        self.mid = nn.Sequential(nn.Conv2d(ch * 2, ch * 2, 3, padding=1), nn.SiLU())
        self.up = nn.Sequential(nn.ConvTranspose2d(ch * 2, ch, 4, 2, 1), nn.SiLU())    # 28x28
        self.out = nn.Conv2d(ch * 2, 1, 3, padding=1)

    def forward(self, x, t):
        h1 = self.down1(x) + self.t_emb(t.float().view(-1, 1) / T)[:, :, None, None]  # inject time
        h = self.up(self.mid(self.down2(h1)))
        return self.out(torch.cat([h, h1], 1))                                          # skip connection

net = TinyUNet().to(device)
opt = torch.optim.AdamW(net.parameters(), lr=2e-4)
for epoch in range(15):
    for x, _ in dl:
        x0 = x.to(device) * 2 - 1
        t = torch.randint(0, T, (x0.size(0),), device=device)
        eps = torch.randn_like(x0)
        a = abar[t][:, None, None, None]
        xt = a.sqrt() * x0 + (1 - a).sqrt() * eps
        loss = F.mse_loss(net(xt, t), eps)                     # predict the noise
        opt.zero_grad(); loss.backward(); opt.step()
    print(epoch, round(loss.item(), 4))

@torch.no_grad()
def sample(n=16):
    x = torch.randn(n, 1, 28, 28, device=device)
    for t in reversed(range(T)):
        eps = net(x, torch.full((n,), t, device=device))
        x = (x - betas[t] / (1 - abar[t]).sqrt() * eps) / alphas[t].sqrt()
        if t > 0:
            x += betas[t].sqrt() * torch.randn_like(x)
    return (x.clamp(-1, 1) + 1) / 2
```

This tiny model produces recognisable digits. Real models use deep U-Nets or Transformers (DiT) with attention, sinusoidal time embeddings and text conditioning.

## Making diffusion practical

<Level l="advanced" />

| Technique | Purpose |
|---|---|
| Latent diffusion | Diffuse in a VAE's compressed latent space: ~50× cheaper |
| Text conditioning | Cross-attention to text-encoder embeddings (CLIP, T5) |
| Classifier-free guidance | Train with and without the prompt; at sampling ε = ε_uncond + w·(ε_cond − ε_uncond), with w ≈ 5–8 |
| Faster samplers (DDIM, DPM-Solver) | 20–50 steps instead of 1,000 |
| Distillation (LCM, SDXL-Turbo) | 1–4 steps |
| ControlNet | Condition on edges, poses or depth maps |
| LoRA / DreamBooth | Personalise to a style or subject from a few images |
| Inpainting / img2img | Edit part of an image; start from a noised input image |
| Flow matching / rectified flow | Learn straight paths from noise to data (newer image models) |

```python title="sdxl.py"
import torch
from diffusers import StableDiffusionXLPipeline

pipe = StableDiffusionXLPipeline.from_pretrained(
    "stabilityai/stable-diffusion-xl-base-1.0", torch_dtype=torch.float16).to("cuda")
img = pipe(prompt="product photo of a steel water bottle on a wooden desk, studio lighting",
           negative_prompt="blurry, low quality, text, watermark",
           num_inference_steps=30, guidance_scale=6.5).images[0]
```

## Comparing the families

<Level l="advanced" />

| | VAE | GAN | Diffusion | Autoregressive |
|---|---|---|---|---|
| Sample quality | Blurry | Sharp | State of the art (images) | State of the art (text) |
| Diversity | Good | Risk of mode collapse | Excellent | Excellent |
| Training stability | Stable | Unstable | Stable | Stable |
| Sampling speed | One pass | One pass | Many steps (few with distillation) | One pass per token |
| Likelihood | Lower bound | None | Lower bound | Exact |

## Responsible image generation

<Level l="intermediate" />

Generated images raise real risks: deepfakes, non-consensual imagery, copying an artist's style or copyrighted characters, and misinformation. Production systems:

- run **safety classifiers** on prompts and outputs;
- **block generation of real people's likenesses**;
- attach **provenance metadata** and invisible watermarks (C2PA content credentials, SynthID-style watermarks);
- respect the **licence terms** of training data and model weights.

<Interview>
<QA q="What is the reparameterisation trick and why is it needed?">
Sampling z from N(μ, σ²) isn't differentiable. Writing z = μ + σ·ε with ε ~ N(0, 1) moves the randomness into ε, so gradients can flow through μ and σ during backpropagation.
</QA>
<QA q="What does a diffusion model actually learn to predict?">
The noise ε that was added to a clean image at a randomly chosen step t, trained with a simple mean-squared error. Generation repeatedly subtracts the predicted noise, starting from pure noise.
</QA>
<QA q="What is mode collapse?">
A GAN failure where the generator produces only a few kinds of output that reliably fool the discriminator, instead of covering the full variety of the data.
</QA>
</Interview>

<Takeaways>
- VAE: reconstruction loss plus a KL term; smooth latent space; blurry samples.
- GAN: generator versus discriminator; sharp but unstable to train.
- Diffusion: learn to predict added noise, sample by iterative denoising; latent diffusion and guidance power modern image models.
- Ship image generation with safety classifiers, likeness blocking, provenance and licence checks.
</Takeaways>
