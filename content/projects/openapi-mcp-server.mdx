## What you'll build

A generator that reads an **OpenAPI specification** and exposes the API as a **well-curated MCP server**. Any MCP-compatible assistant or agent can then look up employees, create records or check statuses. You'll add OAuth2 authentication, pagination, response trimming, read/write risk levels, an audit log, and an evaluation of how accurately agents pick the right tools.

**Why it stands out:** enterprises have hundreds of internal REST APIs, and "make our APIs usable by agents" is one of the most common AI-engineering tasks today. If you've done API integration work, this project turns that experience directly into AI-engineering proof.

<Note title="Before you start">
Finish [MCP](/learn/mcp/) and [Agent patterns](/learn/agent-patterns/). Time: 12–15 hours.
</Note>

### Success criteria

| Metric | Target |
|---|---|
| Tool-selection accuracy (first tool correct) on 40 requests | ≥ 90% with curated tools |

## Architecture

```mermaid caption="The spec is parsed into a tool registry, filtered and improved by a curation file, and served over MCP. Every call is authenticated, retried sensibly, trimmed for the model and audit-logged."
flowchart TD
  SPEC[openapi.yaml] --> LOAD[Spec loader<br/>resolve $refs]
  CUR[curation.yaml<br/>include · rename ·<br/>describe · risk] --> REG
  LOAD --> REG[Tool registry<br/>name · description ·<br/>JSON schema · risk]
  CL[MCP client<br/>assistant / agent] <-- stdio or<br/>streamable HTTP --> SRV[MCP server]
  REG --> SRV
  SRV --> AUTH[OAuth2 token cache]
  SRV --> EX[HTTP executor<br/>retries · timeouts ·<br/>idempotency keys]
  EX --> API[(Enterprise REST API)]
  SRV --> SH[Response shaper<br/>trim · paginate]
  SRV --> AU[(Audit log)]
```

### 2. Parse the spec into tool definitions

```python title="spec_to_tools.py"
import re
from dataclasses import dataclass, field

@dataclass
class ToolDef:
    name: str
    description: str
    method: str
    path: str
    input_schema: dict
    path_params: list[str] = field(default_factory=list)
    query_params: list[str] = field(default_factory=list)
    has_body: bool = False
    risk: str = "read"                      # read | write | destructive

def resolve_refs(schema, spec, depth=0):
    if depth > 6: return {}
    if isinstance(schema, dict):
        if "$ref" in schema:
            node = spec
            for part in schema["$ref"].lstrip("#/").split("/"): node = node[part]
            return resolve_refs(node, spec, depth + 1)
        return {k: resolve_refs(v, spec, depth + 1) for k, v in schema.items()}
    if isinstance(schema, list): return [resolve_refs(x, spec, depth + 1) for x in schema]
    return schema

snake = lambda s: re.sub(r"[^a-z0-9]+", "_", s.lower()).strip("_")

def load_tools(spec: dict) -> list[ToolDef]:
    tools = []
    for path, item in spec["paths"].items():
        for method, op in item.items():
            if method not in ("get", "post", "put", "patch", "delete"): continue
            props, required, pparams, qparams = {}, [], [], []
            for p in op.get("parameters", []) + item.get("parameters", []):
                p = resolve_refs(p, spec)
                props[p["name"]] = {**p.get("schema", {"type": "string"}), "description": p.get("description", "")}
                if p["in"] == "path": pparams.append(p["name"])
                elif p["in"] == "query": qparams.append(p["name"])
                if p.get("required"): required.append(p["name"])
            body = op.get("requestBody", {}).get("content", {}).get("application/json", {}).get("schema")
            if body:
                props["body"] = resolve_refs(body, spec); required.append("body")
            desc = (op.get("summary", "") + ". " + op.get("description", "")).strip(". ")
            risk = "read" if method == "get" else "destructive" if method == "delete" else "write"
            tools.append(ToolDef(snake(op.get("operationId") or f"{method}_{path}"), desc[:900],
                                 method.upper(), path, {"type": "object", "properties": props, "required": required},
                                 pparams, qparams, bool(body), risk))
    return tools
```

### 3. Curate: generated tools are never enough

Raw APIs make poor agent tools: cryptic operation IDs, thin descriptions, far too many endpoints. A curation file fixes that:

```yaml title="curation.yaml"
include: [search_employees, get_employee, list_departments, list_leave_requests,
          approve_leave_request, create_employee]
overrides:
  search_employees:
    description: >
      Search employees by name, email, department or manager. Returns at most 20 results
      with id, name, title, department. Use this to find an employee's id before calling other tools.
  approve_leave_request:
    description: Approve a pending leave request by id. Only for managers approving their direct reports.
    risk: write
    requires_confirmation: true
  create_employee:
    risk: write
    requires_confirmation: true
response_fields:          # trim responses to what the model needs
  search_employees: [id, name, title, department, email]
  get_employee: [id, name, title, department, manager_id, location, start_date, status]
```

<Tip title="Tool count matters">
Agents choose tools less accurately as the number of tools grows. Thirty endpoints rarely deserve thirty tools. Expose the 5–12 operations users actually need, add composite tools for common multi-call workflows (like `get_employee_with_manager`), and split very large APIs into several focused MCP servers.
</Tip>

### 4. OAuth2 token cache and HTTP executor

```python title="executor.py"
import asyncio, time, uuid, httpx

class TokenCache:
    def __init__(self, token_url, client_id, client_secret, scope=""):
        self.url, self.cid, self.secret, self.scope = token_url, client_id, client_secret, scope
        self.token, self.expiry, self.lock = None, 0, asyncio.Lock()

    async def get(self):
        async with self.lock:
            if self.token and time.time() < self.expiry - 60:
                return self.token
            async with httpx.AsyncClient(timeout=10) as c:
                r = await c.post(self.url, data={"grant_type": "client_credentials", "client_id": self.cid,
                                                 "client_secret": self.secret, "scope": self.scope})
                r.raise_for_status(); data = r.json()
            self.token, self.expiry = data["access_token"], time.time() + data.get("expires_in", 3600)
            return self.token

class Executor:
    def __init__(self, base_url, tokens: TokenCache):
        self.base, self.tokens = base_url.rstrip("/"), tokens
        self.client = httpx.AsyncClient(timeout=20, follow_redirects=False)

    async def call(self, tool, args: dict) -> dict:
        path = tool.path
        for p in tool.path_params:
            path = path.replace("{" + p + "}", httpx.URL(str(args[p])).raw_path.decode().lstrip("/"))  # encode
        params = {q: args[q] for q in tool.query_params if q in args}
        headers = {"Authorization": f"Bearer {await self.tokens.get()}"}
        if tool.risk != "read":
            headers["Idempotency-Key"] = uuid.uuid4().hex
        for attempt in range(3):
            r = await self.client.request(tool.method, self.base + path, params=params,
                                          json=args.get("body"), headers=headers)
            if r.status_code == 429 or r.status_code >= 500:
                await asyncio.sleep(min(float(r.headers.get("Retry-After", 2 ** attempt)), 10)); continue
            break
        if r.status_code >= 400:
            return {"error": f"HTTP {r.status_code}", "detail": r.text[:500]}   # readable for the model
        return r.json() if r.content else {"status": "ok"}
```

### 5. Shape responses for the model

Return only the fields the curation file lists, cap lists at 20 items, and pass through `total` and `next_cursor` with a note like "More results available; refine the search or pass next_cursor." Large raw JSON wastes tokens and confuses tool selection.

### 6. The MCP server

```python title="server.py"
import asyncio, json, logging, os, yaml
import mcp.types as types
from mcp.server.lowlevel import Server
from mcp.server.stdio import stdio_server

cfg = yaml.safe_load(open("curation.yaml"))
tools = {t.name: t for t in load_tools(spec) if t.name in cfg["include"]}
for name, o in cfg.get("overrides", {}).items():
    if name in tools:
        tools[name].description = o.get("description", tools[name].description).strip()
        tools[name].risk = o.get("risk", tools[name].risk)
needs_confirm = {n for n, o in cfg.get("overrides", {}).items() if o.get("requires_confirmation")}

executor = Executor(os.environ["API_BASE"],
                    TokenCache(os.environ["TOKEN_URL"], os.environ["CLIENT_ID"], os.environ["CLIENT_SECRET"]))
audit = logging.getLogger("audit"); server = Server("hr-api-tools")

@server.list_tools()
async def list_tools() -> list[types.Tool]:
    out = []
    for t in tools.values():
        schema = json.loads(json.dumps(t.input_schema))
        if t.name in needs_confirm:
            schema["properties"]["confirmed"] = {"type": "boolean",
                "description": "Must be true only after the user explicitly confirmed this exact action."}
            schema["required"] = schema.get("required", []) + ["confirmed"]
        out.append(types.Tool(name=t.name, description=f"[{t.risk.upper()}] {t.description}", inputSchema=schema))
    return out

@server.call_tool()
async def call_tool(name: str, arguments: dict) -> list[types.TextContent]:
    t = tools.get(name)
    if not t:
        return [types.TextContent(type="text", text=f"Unknown tool {name}")]
    if name in needs_confirm and not arguments.get("confirmed"):
        return [types.TextContent(type="text", text="Not executed: ask the user to confirm this action first.")]
    data = await executor.call(t, arguments)
    audit.info(json.dumps({"tool": name, "risk": t.risk, "args": {k: v for k, v in arguments.items() if k != "body"}}))
    shaped = shape(name, data, cfg.get("response_fields", {}))
    return [types.TextContent(type="text", text=json.dumps(shaped, default=str))]

async def main():
    async with stdio_server() as (read, write):
        await server.run(read, write, server.create_initialization_options())

if __name__ == "__main__":
    asyncio.run(main())
```

<Pitfall title="A confirmation flag is a speed bump, not a lock">
A model can set `confirmed: true` by itself. For real enforcement, the MCP *host* application should require user approval for tools marked write or destructive (many hosts prompt before tool calls), and the API must enforce authorisation using the **end user's** identity, not a super-user service account.
</Pitfall>

Measure exact sequence match, first-tool accuracy, argument validity, unnecessary calls per task, confirmation compliance and success rate. Compare **raw generated tools vs curated tools**: the improvement from curation is your headline result.

## Security checklist

- [ ] Client secrets from a vault or environment; never logged.
- [ ] Path parameters URL-encoded; base URL fixed (the model can't choose hosts, so no SSRF).
- [ ] Destructive endpoints excluded by default; write tools need confirmation in the host.
- [ ] Propagate end-user identity to the API (token exchange) so permissions match the human.
- [ ] Remote (HTTP) mode sits behind authentication and per-client rate limits.
- [ ] Audit log shipped to your log system and retained.

## Deploy it

Serve over streamable HTTP so many clients can share one server. Put it behind your gateway with OAuth for MCP clients, per-client rate limits, and the audit log shipped centrally. Containerise it and inject secrets from a vault.
