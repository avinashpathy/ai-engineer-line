# Agentic Sales-Data Analyst API — starter scaffold

The full guide is on the website: `/projects/sales-data-analyst/`. This folder gives you a sensible layout to start from.

## Setup
```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                # then fill in your keys
python -m pytest -q
```
